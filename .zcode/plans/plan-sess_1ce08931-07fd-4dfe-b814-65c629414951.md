## الهدف: تشغيل تسجيل دخول المدير العام في تطبيق الويب فعلياً

### الوضع المؤكد (بالتشخيص المباشر)
- خادم Vite كان متوقفاً → **أعدت تشغيله** في الخلفية، والآن `/login` يستجيب 200 ✓
- Supabase يصل إليه المفتاح العام بنجاح (اختبار REST: 200، مفتاح خاطئ: 401) ✓
- **المشكلة الوحيدة المتبقية**: لا يوجد حساب بدور `company_director` في قاعدة البيانات (البحث في كل المستودعين: لا توجد بيانات دخول مبرمجة). كلمة المرور مشفّرة ولا يمكن استرجاعها — يجب إنشاؤها في لوحة Supabase.

### الخطوات
**1) [أنت — مرة واحدة] إنشاء حساب المدير العام في Supabase Dashboard → SQL Editor:**
```sql
-- أنشئ حساب المدير (غيّر البريد وكلمة المرور قبل التنفيذ)
select auth.admin_create_user(
  email => 'director@medlink.com',
  password => 'StrongPassword@2026',
  email_confirm => true,
  user_metadata => jsonb_build_object('name', 'المدير العام', 'role', 'company_director')
);

-- فعّل الحساب (الافتراضي pending_approval يمنع الإجراءات الحساسة)
update public.users set account_status = 'active' where role = 'company_director';
```
(يعتمد على الـ trigger الموجود أصلاً `handle_new_user` — لا إدخال يدوي في `public.users`؛ مطابق لبنية المشروع)

**2) [أنت] تحديث الصفحة** بـ Ctrl+F5 ثم الدخول على `http://127.0.0.1:5173` بالبريد وكلمة المرور اللذين أنشأتهما.

**3) [أنت] نشر Edge Function** (كي يعمل إنشاء/إيقاف/إعادة تعيين مدراء الفروع):
```
cd C:\Users\USER\stitch_medlink_yemen-1
supabase functions deploy manage-branch-manager-account --project-ref lmkomzqioneuyvatzsov
```

**4) [أنا — بعد إنشائك الحساب] التحقق الفعلي من المتصفح:**
- تسجيل الدخول → إعادة التوجيه إلى `/director/dashboard`
- فتح صفحة «مدراء الفروع» → قراءة القائمة + إنشاء حساب تجريبي لمدير فرع + إيقاف/تفعيل + إعادة تعيين كلمة مرور
- **فحص أمني إضافي**: استعلام إعدادات التسجيل العام (`/auth/v1/settings`) لتأكيد أنه لا يمكن لأي شخص خارجي تسجيل حساب بدور مدير عبر API التسجيل المفتوح (يتم الإبلاغ عن النتيجة فقط؛ أي تعديل أمني يُترك لقرارك)

**5) بعد النجاح** — المتابعة بالترتيب المعتمد: Dashboard → إدارة الكتالوج → نظرة المخزون → مراقبة الطلبات (كل صفحة تُضبط على مخطط Supabase الفعلي).

### ملاحظات
- لن أعدّل أي شيء في مستودع Flutter (الملف الجديد للـ Edge Function أنشئ سابقاً فقط — لم ألمس أي ملف موجود)
- لا بيانات وهمية: الحساب يُنشأ بحقيقية بواسطتك في Supabase
- لا أستطيع إنشاء الحساب نيابةً عنك (لا يوجد لدي مفتاح service-role؛ والدخول إليه على الجهاز غير متاح)
