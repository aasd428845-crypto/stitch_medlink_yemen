---
name: medlink-repository-audit
description: Perform a non-destructive, comprehensive audit of the MedLink Yemen repository and produce architecture/status maps.
---

Use this skill for the first analysis of the repository or when the project structure is unclear.

Inspect:
- applications and packages
- Flutter/Dart
- Web/Admin
- future Windows target
- Supabase
- database schema/migrations/functions/policies
- authentication and roles
- APIs/data access
- shared models
- docs and existing plans
- `.agents/memory`
- `.zcode/plans`
- assets/screenshots
- tests/build/deployment
- dependency boundaries

Do not modify application code during an audit. Distinguish implemented, partial, planned, missing, duplicated and risky areas.
