# مراجعة شاملة — شاشات مدير الفرع (Stitch Medlink Yemen)

توثيق المراجعة الكاملة لتطبيق مدير الفرع وفق التصميم المعتمد
`لوحة_مدير_الفرع_عصرية-2.html` (ثيم فاتح Material 3).

- المشروع: `stitch_medlink_yemen/medlink_app` (Flutter)
- المشروع المرآة (نفس قاعدة البيانات الحية): `Medlik-Waap` (Web)
- قواعد صارمة:
  - لا `Color(0x…)` خارج `lib/utils/theme.dart` — كل الألوان من `BranchColors`.
  - ملفات العميل/السائق تبقى داكنة وخارج النطاق (لا تُلمس).
  - الملفات المشتركة (`order_status_chip`, `driver_rating_badge`, `error_banner`,
    `app_primary_button`, `app_text_field`) لا تُلمس.
  - كل SQL جديد يُنقل إلى migrations بكلا المشروعين (أرقام متوازية).

## الأقسام المنجزة

### القسم 0 — البنية والألوان (فاتح)
- `theme.dart`: مجموعة رموز `BranchColors` الكاملة (خلفية، أسطح، أساسي، نجاح،
  تحذير، خطر، متأخر، تدرجات `heroGradient` و`tabActiveGradient`…)
  + `AppTheme.branchManagerLight`.
- `branch_manager_design.dart`: بطاقات/عناوين/مقاييس/إجراءات سريعة بهوية موحدة.
- `branch_manager_home_shell.dart`: غلاف فاتح + 6 تبويبات + زر الإعدادات ⚙️.
- إعادة كتابة كل تبويبات الفرع بنمط مقروء بعد أن كانت سطراً مضغوطاً + مسح
  كامل للألوان على 15 ملفاً.
- إصلاح deprecation `value:` ← `initialValue:` وإزالة استيرادات زائدة.

### القسم 1 — الإعدادات
- ورقة `branch_settings_sheet.dart`:
  - بيانات الفرع (اسم/مدينة/عنوان) عبر `branches_manager_update_own`.
  - حسابات الدفع: CRUD + تعيين الحساب الافتراضي
    (`branch_bank_accounts` + `branch_set_default_bank_account`).
  - تفضيلات الإشعارات (4 مفاتيح) في `notification_preferences`.
  - تسجيل الخروج بتأكيد.

### القسم 2 — تخصيص الطلبات
- `branch_allocate_sheet.dart` — "تفاصيل التخصيص" مع 4 خيارات:
  - نقل ذكي (الكل / المتأخرة فقط — مفعّل عبر `scheduledDeliveryAt`).
  - يدوي (جزئي بحد أقصى المتوفر / كامل).
  - جدول أصناف بشارات أخضر/أحمر + كمية قابلة للتعديل.
  - تاريخ تسليم إلزامي يتحكم بتمكين التأكيد.
  - ينفذ `branch_allocate_order` (تخصيص + فاتورة اختيارية + توقيت تسليم).
- زر "تخصيص" على بطاقة الطلب (حالة pending) في التبويبين (لوحة + طلبات).

### القسم 3 — الفواتير
- `models/invoice.dart` (فئة عادية مع `isOverdue`).
- `branch_invoices_tab.dart`: 3 بطاقات (الإجمالي/المدفوع/المتأخر) + بحث
  + إنشاء فاتورة + شارات الحالة (مسدد/معلّق/متأخر/ملغي).
- `branch_invoice_create_sheet.dart`: اختيار عميل + مبلغ + تاريخ استحقاق
  + `InvoiceStatusChip` + عرض تفاصيل الفاتورة.
- الخدمة: `fetchBranchInvoices` (انضمام عبر `invoices_client_id_fkey`)،
  `createInvoice`، `fetchBranchClients`.

### القسم 4 — المخزون
- `branch_inventory_tab.dart` (إعادة كتابة كاملة): كتالوج كامل بكل المنتجات
  + بحث + 5 فلاتر + شارات حالة (نفد/منخفض/ساري/قرب الانتهاء) + كمية قابلة
  للتعديل + مودال "دفعة جديدة" بتاريخ انتهاء + ترقيم صفحات (15/صفحة).
- خدمة `branch_add_stock_batch` + `fetchAllProducts` + `fetchBranchWarehouse`.
- `setProductQuantity` ينشئ صف `inventory` تلقائياً عند غيابه
  (الجدول unique على (branch_id, product_id)).

### القسم 5 — السائقون
- 3 بطاقات إحصائية: إجمالي السائقين / متاحون الآن 🟢 / في مهام نشطة 🟡
  (المشتق من الطلبات الحقيقية).
- زر FAB عائم "إضافة سائق".
- مودال إضافة السائق: زر نسخ 📋 للإيميل وكلمة المرور المؤقتة
  (`Clipboard.setData` + SnackBar "تم النسخ") عبر Edge Function
  `manage-driver-account`.

### القسم 6 — الإحصائيات والتقارير (bento في لوحة التحكم)
كل الأرقام حقيقية من قاعدة البيانات:
- **مبيعات هذا الشهر** (مجموع فواتير الشهر غير الملغاة) + نسبة النمو ▲/▼
  مقارنة بالشهر السابق.
- **طلبات مكتملة هذا الشهر** (من `delivered_at`).
- **دقة التخصيص %** = نسبة التوصيلات التي وصلت في موعدها أو قبله.
- **مخطط التسليم الأسبوعي** (آخر 7 أيام من `delivered_at`) بأعمدة متدرجة.
- **أفضل 3 سائقين** حسب التوصيلات المكتملة.
- **تنبيهات المخزون**: مخزون منخفض/نفد + تنتهي قريباً (من الكتالوج).
- **رؤى مالية**: دائرة تقدم بنسبة المدفوع من إجمالي الفواتير
  + عدد المتأخرات.
