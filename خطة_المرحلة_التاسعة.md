## الجزء الأول: الدردشة الحية (نص)

### من يتحدث مع من؟
- **السائق ↔ مدير الفرع** — غرفة محادثة واحدة لكل طلب (مرتبطة بـ `order_id`).
- **العميل** — لا يدخل الدردشة إطلاقاً، يرى الموقع فقط (الجزء الثاني).

### نقطة الوصول للسائق
التبويب الثالث "الدردشة" في `driver_home_shell.dart` (يستبدل `_DriverChatPlaceholder`):
- قائمة بالطلبات النشطة (`assigned` / `in_progress`) التي يمكن فتح دردشة فيها.
- النقر على طلب → يُنشئ/يفتح غرفة الدردشة المرتبطة به (`ChatRoomScreen`).

### نقطة الوصول لمدير الفرع
تبويب جديد "الدردشة" يُضاف إلى `branch_manager_home_shell.dart` (`BranchChatTab`):
- قائمة المحادثات النشطة: صورة الطلب، اسم السائق، آخر رسالة، وقتها.
- النقر → `ChatRoomScreen`.

### شاشة غرفة الدردشة `ChatRoomScreen`
شاشة مشتركة بين الدورين — تستقبل `roomId` و`orderNumber` و`otherPartyName`:
- **رأس الشاشة:** رقم الطلب + اسم الطرف الآخر.
- **قائمة الرسائل:** مُحدَّثة فورياً بـ Supabase Realtime — لا تحديث يدوي.
- **تمييز بصري:** رسائلي (يمين، خلفية `primary`) — رسائله (يسار، خلفية `surfaceContainerLow`).
- **حقل الإدخال + زر إرسال:** لا يُرسَل إذا كان النص فارغاً.
- **Unsubscribe** تلقائي عند مغادرة الشاشة (`dispose`).

### Supabase Realtime للدردشة
```dart
supabase
  .channel('chat_room:$roomId')
  .onPostgresChanges(
    event: PostgresChangeEvent.insert,
    schema: 'public',
    table: 'chat_messages',
    filter: PostgresChangeFilter(
      type: FilterType.eq, column: 'room_id', value: roomId),
    callback: (payload) => _addMessage(ChatMessage.fromJson(payload.newRecord)),
  )
  .subscribe();
```

## الجزء الثاني: الموقع المباشر للسائق

### كيف يعمل التدفق؟
1. **السائق** يضغط زر **"تحديث موقعي"** في `driver_order_detail_screen.dart` عندما تكون الحالة `in_progress`.
2. التطبيق يقرأ الإحداثيات الحالية عبر `geolocator`، ثم يُخزّنها في جدول `driver_locations` (upsert — صف واحد لكل سائق، يُحدَّث دائماً).
3. **العميل** في `order_detail_screen.dart` يرى ودجت `DriverLocationMap` تُعرض على خريطة Google Maps عندما تكون حالة الطلب `in_progress`.
4. الخريطة تتحرك تلقائياً عند كل تحديث (Supabase Realtime على `driver_locations`).

### متى يظهر الموقع للعميل؟
- ✅ `status = 'in_progress'` فقط.
- ❌ يُخفى للطلبات `pending` / `assigned` / `delivered`.

### طلب صلاحية GPS
في `AndroidManifest.xml` تُضاف:
```xml
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/>
```
وفي Flutter يُطلب الإذن في وقت التشغيل قبل استخدام `geolocator`.

## Schema — Migration `0007_chat_location.sql`

```sql
-- ── جدول غرف الدردشة (واحدة لكل طلب) ──────────────────────────────────────
create table public.chat_rooms (
  id         uuid primary key default gen_random_uuid(),
  order_id   uuid not null references public.orders(id) on delete cascade,
  driver_id  uuid not null references public.users(id),
  branch_id  uuid not null references public.branches(id),
  created_at timestamptz not null default now(),
  unique(order_id)
);

-- ── جدول الرسائل ────────────────────────────────────────────────────────────
create table public.chat_messages (
  id         uuid primary key default gen_random_uuid(),
  room_id    uuid not null references public.chat_rooms(id) on delete cascade,
  sender_id  uuid not null references public.users(id),
  content    text not null,
  created_at timestamptz not null default now()
);

-- ── جدول مواقع السائقين (upsert — صف واحد لكل سائق) ────────────────────────
create table public.driver_locations (
  driver_id  uuid primary key references public.users(id) on delete cascade,
  latitude   double precision not null,
  longitude  double precision not null,
  updated_at timestamptz not null default now()
);

alter table public.chat_rooms       enable row level security;
alter table public.chat_messages    enable row level security;
alter table public.driver_locations enable row level security;

-- ── RLS: chat_rooms ─────────────────────────────────────────────────────────
-- السائق أو مدير فرعه يرى الغرفة وينشئها
create policy "chat_rooms_member_select"
  on public.chat_rooms for select
  using (
    driver_id = auth.uid()
    or (public.current_user_role() = 'branch_manager'
        and branch_id = public.current_user_branch_id())
  );

create policy "chat_rooms_member_insert"
  on public.chat_rooms for insert
  with check (
    driver_id = auth.uid()
    or (public.current_user_role() = 'branch_manager'
        and branch_id = public.current_user_branch_id())
  );

-- ── RLS: chat_messages ───────────────────────────────────────────────────────
-- فقط أعضاء الغرفة يقرأون ويُرسلون
create policy "chat_messages_member_select"
  on public.chat_messages for select
  using (
    exists (
      select 1 from public.chat_rooms r
      where r.id = room_id
        and (r.driver_id = auth.uid()
             or (public.current_user_role() = 'branch_manager'
                 and r.branch_id = public.current_user_branch_id()))
    )
  );

create policy "chat_messages_member_insert"
  on public.chat_messages for insert
  with check (
    sender_id = auth.uid()
    and exists (
      select 1 from public.chat_rooms r
      where r.id = room_id
        and (r.driver_id = auth.uid()
             or (public.current_user_role() = 'branch_manager'
                 and r.branch_id = public.current_user_branch_id()))
    )
  );

-- ── RLS: driver_locations ────────────────────────────────────────────────────
-- السائق يُحدّث موقعه فقط
create policy "driver_locations_own_upsert"
  on public.driver_locations for all
  using  (driver_id = auth.uid())
  with check (driver_id = auth.uid());

-- العميل ومدير الفرع يقرآن مواقع السائقين
create policy "driver_locations_parties_select"
  on public.driver_locations for select
  using (
    public.current_user_role() in ('client', 'branch_manager')
    or driver_id = auth.uid()
  );
```

## استعلامات Supabase المطلوبة

### `ChatService.getOrCreateRoom(orderId, driverId, branchId)`
```dart
// upsert: ينشئ الغرفة إن لم تكن موجودة، ويعيد الموجودة إن وُجدت
final row = await _client
    .from('chat_rooms')
    .upsert(
      {'order_id': orderId, 'driver_id': driverId, 'branch_id': branchId},
      onConflict: 'order_id',
    )
    .select()
    .single();
return ChatRoom.fromJson(row);
```

### `ChatService.fetchRoomsForDriver()`
```dart
// كل الغرف التي يكون المستخدم الحالي هو سائقها
await _client
    .from('chat_rooms')
    .select('*, order:orders(id, status, total_amount)')
    .eq('driver_id', _client.auth.currentUser!.id)
    .order('created_at', ascending: false);
```

### `ChatService.fetchRoomsForBranch(branchId)`
```dart
await _client
    .from('chat_rooms')
    .select('*, order:orders(id, status), driver:users!chat_rooms_driver_id_fkey(name, phone)')
    .eq('branch_id', branchId)
    .order('created_at', ascending: false);
```

### `ChatService.fetchMessages(roomId)`
```dart
await _client
    .from('chat_messages')
    .select('*, sender:users!chat_messages_sender_id_fkey(name, role)')
    .eq('room_id', roomId)
    .order('created_at');
```

### `ChatService.subscribeToRoom(roomId, onNewMessage)`
```dart
return _client
    .channel('chat_room:$roomId')
    .onPostgresChanges(
      event: PostgresChangeEvent.insert,
```

## الأمان والـ RLS

| التهديد | الحماية |
|---------|---------|
| سائق يقرأ دردشة طلب ليس معيّناً له | `chat_rooms_member_select` تتحقق `driver_id = auth.uid()` |
| مدير فرع يقرأ دردشة فرع آخر | الشرط `branch_id = current_user_branch_id()` في كلٍّ من `select` و`insert` |
| مستخدم يُرسل رسالة بـ `sender_id` مزوَّر | `chat_messages_member_insert` تُلزم `sender_id = auth.uid()` |
| سائق يُحدّث موقع سائق آخر | `driver_locations_own_upsert` تُلزم `driver_id = auth.uid()` |
| تسرب channel Realtime في الذاكرة | `unsubscribe()` إلزامي في `dispose()` لكل subscription |

## قرارات معمارية مهمة

1. **غرفة واحدة لكل طلب** (`unique(order_id)`) — `getOrCreateRoom` بـ upsert لتجنب تكرار الإنشاء.

2. **`ChatController` منفصل لكل شاشة** — لا controller مشترك واحد لجميع الغرف؛ كل `ChatRoomScreen` تُنشئ subscription خاصة بها وتلغيها عند الخروج.

3. **لا polling** — الدردشة والموقع حيّان بالكامل عبر Realtime فقط؛ ممنوع استخدام `Timer.periodic` لجلب الرسائل أو الموقع.

4. **طلب صلاحية GPS في وقت التشغيل** — استخدم `geolocator` لفحص الإذن أولاً؛ إذا رُفض تُعرض رسالة `driverLocationPermissionDenied` بدلاً من رمي خطأ.

5. **`build_runner`** — بعد إنشاء `chat_room.dart` و`chat_message.dart` يجب تشغيل:
   ```bash
   cd medlink_app && flutter pub run build_runner build --delete-conflicting-outputs
   ```
